MONITORED DIRECTORY
===================

This folder contains files that are monitored by SentinelCheck
for integrity verification.

Files in this directory:
  - config.txt     : Application configuration
  - users.csv      : Authorized user accounts
  - settings.json  : Monitoring agent settings
  - server.conf    : Network server configuration
  - readme.txt     : This file

Any unauthorized modification, deletion, or addition of files
in this directory will be detected and reported by SentinelCheck.
